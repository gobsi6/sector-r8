# SECTOR R-8 — 게임 서버

계정, 캐릭터 생성, 요원 목록과 접속 상태, 통신 채널(채팅)을 맡는 Node 서버입니다.
화면(`public/index.html`)도 이 서버가 함께 내보냅니다.

## 폴더 구성

```
sector-r8/
├─ server.js          서버 본체 (Express + Socket.io + SQLite)
├─ package.json
├─ package-lock.json
├─ public/
│  └─ index.html      게임 화면
└─ .gitignore
```

## Railway에 올리기

1. **GitHub에 저장소 만들기**
   GitHub에서 새 저장소(예: `sector-r8`)를 만들고 위 파일들을 올립니다. `node_modules`와 `data` 폴더는 올리지 않습니다.

2. **Railway에 서비스 추가**
   dragon-game이 있는 프로젝트 캔버스에서 **+ Create → GitHub Repo → sector-r8**을 고릅니다.
   새 프로젝트로 따로 만들어도 됩니다. 어느 쪽이든 dragon-game과는 서로 영향을 주지 않습니다.

3. **볼륨 붙이기**
   새로 생긴 서비스 카드를 오른쪽 클릭하거나 **+ Create → Volume**으로 볼륨을 만들고, 이 서비스에 연결합니다.
   마운트 경로는 `/data`로 둡니다. 서버가 볼륨 경로를 알아서 찾아 데이터베이스 파일을 그 안에 저장합니다.
   볼륨이 없으면 다시 배포할 때마다 계정과 캐릭터가 지워집니다.

4. **주소 만들기**
   서비스 → **Settings → Networking → Generate Domain**을 누르면 `xxx.up.railway.app` 주소가 생깁니다.

5. 그 주소로 들어가면 바로 출입 인증 화면이 나옵니다.

> 서버는 **1개(레플리카 1)** 로만 돌려야 합니다. 데이터베이스 파일과 접속 상태를 한 서버가 들고 있기 때문입니다.

## 로컬에서 돌려 보기

```
npm install
npm start
```

`http://localhost:3000`으로 접속합니다. 데이터는 `./data/sector-r8.db`에 저장됩니다.
`public/index.html`을 서버 없이 파일로 열면 데모 모드(브라우저 안에서만 동작)로 켜집니다.

## 서버가 하는 일

| 기능 | 방식 |
|---|---|
| 가입·로그인 | 아이디(영문·숫자·밑줄 4~20자) + 비밀번호 (bcrypt로 암호화 저장), 로그인 토큰 발급 |
| 출입증 발급 | 스탯 합계, 범위, 부서 기능, 넘버 중복을 서버가 다시 검사 |
| 봉인 기록 | 본인 요청에만 내려줌. 다른 요원에게는 공개 정보만 전송 |
| 요원 목록·접속 상태 | 실시간 연결 수로 판단 |
| 통신 채널 | 전체 / 개인, 최근 300개 보관, 300자 제한 |
| 보급 상점 | 보급품으로 작전 소모품(구급 키트·진정제·섬광탄), 장비(방호구·도구 칸), 출입증 테두리를 산다. 칭호는 팔지 않고 업적으로 얻는다 |
| 튜토리얼 | 새 요원은 재생 수조에서 깨어나 훈련 작전 「첫 출동」을 한다(리퍼 동행). 진행은 브라우저에서, 보상(보급품 20·칭호)만 서버가 준다 |
| 작전 | 대기실 참가(최대 3명) + 출발 장비 선택 → 라운드마다 각자 행동을 하나씩 고름(제한 시간) → 고른 순서대로 실행 후 하수인·개체·귀환 신호 진행 → 성공·실패·중단. 판정은 서버가 굴림 |
| 판정 | d6 주사위 풀. 스탯 + 기능 등급 + 지원 주사위. 오염도 20%마다 오염 주사위 1개 |
| 교전 | 하수인은 다음 행동을 예고한다. 공격·밀쳐 내기·막기·협공(+2) |
| 출발 장비 | 대기실에서 작전마다 하나 챙긴다(무료). 역할은 없다. **무기**: 공격 주사위 +1, 맞히면 피해 +1. **탐지기**: 은신 판정 주사위 +1, 하수인 회피 확률 증가. **구급상자**: 응급처치·정신 안정 주사위 +1, 기능 없이도 치료 가능, 구급 키트 1회분. **통신기**: 장면 행동(관찰·해독·설치 같은 공격 말고 카드) 주사위 +1. RAVEN-1 지원은 누구나 작전당 한 번 |
| 관제 (NPC) | 이름 없는 「관제실」이 무전으로 명령을 하달한다. 개체 거리를 알려 주고, 갈림길에 들어서면 문 하나 너머를 알아서 확인해 준다. 전투 작전에서는 계수자 체력이 절반 아래로 떨어지는 순간 구속 장치를 자동으로 가동해 한 라운드 묶는다. 요청 목록·잡음은 없다 |
| 하수인 회피 | 하수인은 셈이 줄 때 나오는데, 관제실이 한 턴 먼저 「전원 정지하고 숨을 것」을 하달한다. 그 라운드에 전원이 조용히 있고(숨는다·대기) 숨기(민첩 + 은신, 쉬움, 탐지기 +1) 성공이 인원 절반 이상이면 하수인이 지나간다. 전진·공격은 소리를 내서 들킨다 |
| 하수인 예고 | 하수인이 이번 라운드 끝에 할 행동이 늘 보인다(어둠과 상관없이). 물기·비명 → 막기로 절반, 부르기 → 이번 라운드에 쓰러뜨리지 못하면 하나 더, 웅크림 → 이번 라운드 공격 피해 절반, 비틀거림 → 행동 없음 |
| 작전 종류 | **탐사**(R8-P 하층 탐사): 들어갈 때마다 바뀌는 하층을 지나 승강기까지, 연구 자료 4·보급품 10. **소탕**(R8-S B2 배양 구역 소탕, 정기): 한 장면, 라운드마다 배양체가 몰려오고 인원별 6·11·12·14마리를 처리하면 성공, 보급품 45. 이동 없음. **확보**(R8-14 「계수자」 재확보, 이벤트): 복도 진입 → 격리실에서 개체 체력을 0으로 만들면 성공 |
| 작전 주사위 상한 | 작전 판정은 한 번에 최대 6개만 굴린다(`R8_DICE_CAP`). 넘친 주사위는 2개당 맞혔을 때 공격 피해 +1. 격리 관리 판정에는 상한이 없다 |
| 공격 판정 | 공격은 필요 수(보통 2)에 못 미치면 빗나간다(하나 모자란 「대가 있는 성공」이 없다). 대성공은 필요 수보다 2개 이상 많고 최소 4개일 때 |
| 단순화 | 대열 위치 제한(선두만 전진, 끝자리만 공격 등)과 거리 조건, 관제실 요청 목록, 무전 잡음, 구조 변형을 뺐다. 전진·대기·후퇴와 공격·밀쳐내기는 누구나 할 수 있다. 대열 순서는 하수인이 누구를 무는지에만 쓰인다 |
| 팀 연계 · 일제 사격 | 판정이 성공이면 게이지 1칸, 대성공이면 2칸(최대 6 + 2×인원). 가득 차면 라운드 끝에 「RAVEN 일제 사격」: 하수인을 모두 쓸고, 계수자에게 6 + 2×인원 피해, 둘 다 없으면 남은 시간 +1 |
| 연출 · 결과 | 새 판정이 들어오면 화면 가운데에 주사위가 굴러가다 멈추고 결과·피해 숫자가 튀어나온다(대성공·일제 사격은 화면 흔들림). 결과 화면에 요원별 입힌 피해와 MVP가 나온다. 계수자 체력은 인원별 30·34·32·36. 주사위 연출에는 굴린 주사위 수, 5·6 개수와 필요 수, 피해 계산(성공 수·무기·협공 등)이 함께 나온다. 누르면 넘어간다 |
| 제압전 | 개체 체력 20 + 인원당 9. 라운드마다 다음 행동이 보인다: 손 뻗기(대상자 피하기·동료 막기) / 셈(모두 정신력 피해·남은 시간 −1, 그 라운드에 합쳐서 4 이상 때리면 끊김) / 부르기(하수인) / 웅크림(피해 절반) / 틈(피해 +2). 앞에 하수인이 있으면 개체를 칠 수 없다. 장면 행동: 급소 짚기(피해 +3), 주의 끌기(다음 손 뻗기를 받아 냄), 섬광탄(개체 행동 하나 막기). 구속 장치 요청(개체 행동 하나 막기). 협공 +2 |
| 작전 길이 | 한 판 약 15라운드 안팎. 전진 한 번 15m, 남은 시간 6칸 |
| 개체 회피 | 이번 라운드 끝에 개체가 닿을 것 같으면 관제실이 대상자(그쪽 끝 요원)를 부른다. 대상자는 「피한다」(민첩 + 은신, 보통, 탐지기 +1)에 성공하면 빗나가고 개체가 더 멀리(물러나는 거리 + 6m) 물러난다. 동료가 「막기」를 고르면 피해 절반. 개체는 닿은 뒤 12m 물러난다(R8-P는 12m) |
| 하층 탐사 | 들어갈 때마다 도면이 바뀐다(구역 2곳 + 갈림길 1곳 + 상층 승강기). **갈림길**: 관제실이 문 하나 너머를 미리 알려 주고, 현장은 문 A·B에 투표한다(동률이면 먼저 고른 쪽, 첫 라운드에 무표면 기다리고 그다음은 무작위). 위험: 루프·하수인 둥지·개체 근접·보급 상자 |
| 재생 | 작전 중 사망하면 재생 수조로. 오염도 +10%, 변질 특성 추가(최대 5개), 기본 6시간 대기 |
| 작전 기록 | 끝난 작전과 판정 기록 전체를 저장 |

### 설정값 (Railway Variables)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `REGEN_HOURS` | `6` | 재생 수조 대기 시간(시간). 테스트할 때는 `0.05`(3분)처럼 줄여 쓸 수 있습니다 |
| `DECAY_PER_HOUR` | `2` | 위협 등급 Ⅲ 개체의 격리 안정도가 시간당 떨어지는 양(%). 등급 Ⅰ은 ×0.5, Ⅱ ×0.75, Ⅳ ×1.25, Ⅴ ×1.5 |
| `R8_SCALE` | (없음) | 인원 보정 값을 덮어쓴다(JSON). 기본값과 조정 방법은 `server.js`의 SCALE_T·SCALE_F와 `tools/balance-sim.js` 참고 |
| `RAVEN_LOCK_HOURS` | `3` | 격리 실패로 RAVEN-3이 투입됐을 때 해당 작전이 봉쇄되는 시간(시간) |
| `RAVEN4_DELAY_HOURS` | `2` | 동료가 회수하지 못해 RAVEN-4가 회수한 요원에게 더해지는 재생 시간(시간) |
| `QUARANTINE_HOURS` | `4` | 오염 한계를 넘은 요원이 격리 관찰되는 시간(시간) |
| `GM_LOGINS` | `admin` | GM 도구를 쓸 계정의 로그인 아이디. 여러 개면 쉼표로 구분 (예: `kint,gm2`). 대소문자 무시 |
| `TASK_MINUTE_MS` | `60000` | 관리 작업의 1분 길이(ms). 테스트할 때만 줄인다 |

> 진행 중인 작전은 서버 메모리에 있습니다. 작전 도중 서버를 다시 배포하면 그 작전은 사라집니다(끝난 작전 기록은 남습니다).

오염도와 자원, 판정 결과는 서버만 바꿀 수 있습니다.

## 밸런스 시뮬레이터

`node tools/balance-sim.js server.js 300` — 실제 서버 규칙 코드를 불러와 봇 요원으로 작전을 조합(작전 × 현장 1~4명)마다 300판씩 돌리고 성공률·실패 원인·사망 수를 JSON으로 출력한다. 서버를 띄우지 않으며 임시 데이터베이스를 쓴다. 봇은 판마다 처음 상태(기능 등급 포함)로 되돌아간다.

| 환경 변수 | 뜻 |
|---|---|
| `OPS` | 돌릴 작전(쉼표 구분, 예: `R8-P`) |
| `SKLV` | 봇 기능 등급(기본 1, 중견 요원은 3) |
| `CLS` | 봇 출발 장비 편성, 예: `weapon,medkit,radio` (기본: 1명 무기, 2명 무기·통신기, 3명 +구급상자) |
| `R8_SHIFT` | 구조 변형 확률(기본 0, 꺼 둠) |
| `R8_FORK` | `0`이면 갈림길 없이 예전 순찰 |
| `PEEK` | `작전,현장 수` 한 판을 돌리고 기록을 출력 |
